# IQChatJournal

> A comprehensive system for capturing, organizing, and exporting AI chat conversations into structured markdown, text, and PDF formats.

## Features

- Browser extension for real-time capture of AI chat interactions.
- Automated file watching and indexing of downloaded conversation data.
- Multi-format export capabilities supporting Markdown, PDF, and plain text.
- Integrated GUI for managing, monitoring, and viewing processed AI transcripts.
